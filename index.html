Wdrożenie na serwer

Postaw backend za darmo na Render.com — krok po kroku.

🎯 Po wdrożeniu asystent działa 24/7 na serwerze — ty i klienci możecie wyłączyć komputer.
Krok po kroku
1

Wgraj kod na GitHub

Wejdź na github.com → "New repository" → nazwa: "ai-asystent" → wgraj wszystkie pliki z folderu który pobrałeś od Claude.

2

Załóż konto na Render.com

Wejdź na render.com → "Get Started for Free" → zaloguj się przez GitHub.

3

Utwórz nowy Web Service

Kliknij "New +" → "Web Service" → wybierz swoje repo "ai-asystent" → Build Command: npm install → Start Command: node server.js

4

Dodaj zmienne środowiskowe

W ustawieniach serwisu → "Environment" → dodaj:
ANTHROPIC_API_KEY = twój klucz API
FB_VERIFY_TOKEN = wymyśl dowolne hasło (np. moj_token_123)
FB_PAGE_TOKEN = token strony Facebook (opcjonalnie)

5

Deploy!

Kliknij "Create Web Service" → Render automatycznie zbuduje i uruchomi serwer. Po 2-3 minutach dostaniesz URL w stylu: https://ai-asystent-xyz.onrender.com

6

Podłącz Facebook (opcjonalnie)

W Facebook Developers → Messenger → Webhooks → wpisz URL: https://TWOJ-URL.onrender.com/webhook/facebook i token weryfikacyjny który ustawiłeś.

Koszty

✅ Render.com — DARMOWY plan wystarczy na start (750h/mies.)
